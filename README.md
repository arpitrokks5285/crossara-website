# Crossara website

Official static website for Crossara, published through GitHub Pages at [crossara.app](https://crossara.app/).

The site uses plain HTML and CSS with no third-party scripts, fonts, analytics, trackers, or cookies. Legal copy distinguishes current pre-launch data practices from planned AdMob, UMP, billing, and integrity features.
