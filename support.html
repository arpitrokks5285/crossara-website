Quick fixes

My crosshair is gone
  1. Open CROSSARA.
  2. If Overlay Permission is missing, tap GRANT PERMISSION.
  3. Enable Display over other apps for CROSSARA in Android system settings.
  4. Return to CROSSARA.
  5. Tap START CROSSHAIR on the Control Deck.

Still disappearing? In Settings → Power Management, set Battery usage to Unrestricted. When applicable, allow CROSSARA through Game Mode or Game Booster restrictions, avoid aggressive game or battery modes, keep CROSSARA available in Recent Apps, and keep its active foreground-service notification visible.

How do I restore my purchase?

Tap a locked design or a premium control such as Rotation. In the CROSSARA upgrade dialog, tap Restore Purchases at the bottom.

Internet access is required for Google Play reconciliation. Make sure you are signed into the Google Play account that owns the purchase.

What’s the difference between PLUS and ULTIMATE?

CROSSARA PLUS

Permanent access to:

  • PRO designs
  • RGB Glow
  • Rotation
  • Ad-free

PRECISION designs and Custom PNG remain available through rewarded 3-Hour Trials.

CROSSARA ULTIMATE

Permanent access to:

  • BASIC
  • PRO
  • PRECISION
  • Custom PNG
  • RGB Glow
  • Rotation
  • Ad-free
How does the 3-Hour Trial work?
  • PRO design → 1 rewarded ad
  • PRECISION design → 2 rewarded ads
  • Custom PNG → 2 rewarded ads
  • Access lasts 3 hours

There is currently no active daily limit. Temporary access can be obtained again after it expires.

My Custom PNG won’t load

Select the PNG through Android’s system file picker. Transparency is supported, and the image is processed locally.

If the original file is moved, deleted, or no longer accessible, re-import it. CROSSARA may show “Custom image unavailable.”
